# Happy Memes: test run, 2026-10-01

Twenty image memes made with [`plugins/happy-memes/skills/meme/SKILL.md`](../plugins/happy-memes/skills/meme/SKILL.md), using GPT image generation and fresh research on that week's news. Images here are JPEG copies of the PNG originals. Nothing has been posted.

- **01–07** were made by a GPT-6 Astra subtask running the skill. Its session then crashed twice (Codex WebSocket 1006).
- **08–20** were made by the parent agent following the same skill with the same image tool.

The mix:
- **AI:** 13 memes (01–13).
- **General audience:** 7 memes (14–20).
- **Where the joke came from:** 11 riff on jokes people already posted and credit the handle; 9 are originals.

## Top 5

1. **[12 Name your AI agent anything](ai/12-name-your-agent-cups.jpg)**: a coffee-cup name mixup that works for insiders and for people who've never heard of Dots.
2. **[08 Argon marquee](ai/08-argon-marquee.jpg)**: the sharpest version of the "model launches are movie trailers now" joke.
3. **[10 Always-on group chat](ai/10-always-on-group-chat.jpg)**: "Seen by Claude" turns the Anthropic-is-quiet thread into a single image.
4. **[14 Sept 30 / Oct 1 / Nov 1 lawn](culture/14-sept30-oct1-lawn.jpg)**: dated today, works for any audience, and adds a third panel to a well-known format.
5. **[02 Increasingly efficient cereal](ai/02-increasingly-efficient-cereal.jpg)**: OpenAI's own euphemism, put on a box that shrank.

## Skill feedback (folded into `SKILL.md` v0.1.0)

- **Mascots.** Run 1 put Microsoft's Clippy on the Pro 500 meme. The line "use copyrighted characters" didn't stop it. **Changed to:** "Don't depict real people's likeness, copyrighted characters or recognizable brand mascots (no Clippy)…"
- **Text rendering was not the problem.** All 20 images rendered every quoted string correctly on the first generation, including handwriting on cups and stamp lettering. Quoting each string with its position and font was enough, and the two-tries fallback was never needed. The remaining failures were about the jokes, not spelling.
- **Absurd literalism won.** The best images put the joke on a physical object: a cereal box, a report card, a marquee, coffee cups, a break-glass box. Text on an object renders cleanly and reads as a real photo. **Changed:** the format list now leads with "Absurd literalism", marked as the most reliable for image models.
- **Batches.** "Draft 5 or more captions" per meme is heavy across 20 memes. A shared joke sheet with 2–3 angles per moment worked better. **Changed to:** "Draft 5 or more captions per topic (for a batch, one joke sheet across topics)…"
- **Credit riffs.** The skill asked for "a sharper version of the best existing joke" but never said to credit it. **Added:** "credit its @handle when you deliver".
- **Posting guidance was missing.** For trend memes the most useful extra field was whether to post standalone or as a quote-tweet, plus a "dead by" date. **Added** to Deliver.
- **Save as you go.** Two runs crashed before saving anything. **Added:** "In a batch, save each image as soon as it passes the check."
- **Real species and places.** The tilcayo image is a generated illustration. **Added:** the alt text has to say so when an image depicts a real animal, place or product.
